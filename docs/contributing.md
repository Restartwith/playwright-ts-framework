# Contributing

## Workflow
1. Create a feature branch from main.
2. Add or update tests for the behavior you change.
3. Run the relevant Playwright suite locally.
4. Open a pull request with a clear summary.

## Code style
- Keep code readable and consistent.
- Prefer reusable helpers over duplicate logic.
- Use typed variables and page objects where possible.

## Before submitting
- Run the tests locally.
- Ensure new tests are stable and not flaky.
- Update documentation if behavior or structure changes.

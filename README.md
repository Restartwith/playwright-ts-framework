# Playwright TypeScript Framework

## Overview
This project is a scalable Playwright + TypeScript test automation framework built around the SauceDemo app.

## Structure
- tests/: test specs
- pages/: page object classes
- fixtures/: reusable test fixtures
- utils/: shared helpers and test data

## Scripts
- npm run test: execute all tests
- npm run test:headed: run tests in headed mode
- npm run test:debug: run tests in debug mode
- npm run report: open the HTML report

## Environment
Copy .env.example to .env and update credentials if needed.
